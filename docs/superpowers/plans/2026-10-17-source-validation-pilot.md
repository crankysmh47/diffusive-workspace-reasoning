**Goal:** Run the registered K0/EX K1/EX K4 source-only diagnostic with detached execution, complete boundary recovery, strict paired exposure and preserved outcomes.

**Architecture:** Keep the closed overfit untouched. Reuse existing native host, complete checkpoint, sampler, batching, answer loss, full-prefix decoder loop, RunRecord and verified Windows process primitives. **Spec:** [source_validation_pilot_design.md](../../source_validation_pilot_design.md), including builder-check resolutions and metadata inventory. [Source controls](../../source_controls_design.md) must clear review before Task2 consumes them or any GPU invocation.

## Global constraints

- Exactly512 net batch1 updates per arm; full2436 ordered source_train IDs, paired sampler/noise; no weight reuse from trained runs.45 fixed metadata-selected validation IDs,9 per pooled fine stratum.
- Exactly K0, EX K1, EX K4; fixed N64/d768/capacity4/native interface/precision. K0 reader-only AdamW; common initialization, explicit horizon and exact active parameter counts.
- Original frozen338 hashes, prompt-only X, all recurrent gradients, no protected task semantics, no truncation or silent model/dtype/split substitution.
- Official stages initial0/final512; K4 persisted final workspace bank and zero/noise/shuffle stages. One committed receipt per stage, fixed checkpoint, no score selection.
- One seed, zero scientific retries,3 sequential arms, at most2 interruption recoveries per arm inside original5400s wall/5460s watchdog. Hard caps and numerical gates exactly as spec.
- All failures/partials retained; no repaired corrupt terminal/cursor, no reset budget, no duplicate live worker. Confirm exact clean source/config/runtime on first launch and every recovery.
- No product code outside assigned files without root ruling. Existing overfit and pinned feasibility/generation files remain unchanged. Optional ML checks must skip only genuinely absent direct dependencies.

## Review focus

- Recovery after a committed stage must reuse its exact predictions/bank; partial stage failures must never select a better attempt.
- K0's active set, horizon, init, sampler and noise must remain paired after checkpoint restoration; source identity alone is insufficient method identity.
- Native greedy loop handles EOS/malformed/capped output exactly, and teacher-forced calls, prompt encodes and incomplete work are separately costed.
- Surviving actual Windows worker/launcher cannot be duplicated after supervisor loss; PID reuse, frozen heartbeats and corrupt cached status must fail closed.
- A full learning PASS with missed workspace screen is a preserved scientific NO_GO; no transfer training follows automatically.
