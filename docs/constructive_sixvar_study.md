Preserve constraint-task-v1, domain 0/1/2, modulus 3, prompt/answer serialization, canonical content/structure/lineage identities, source content-hash and development structure-hash splits. Certificates guarantee necessity, not uniqueness, difficulty, capacity or learned reasoning.

## Single construction path

Fixed root seed 20261011. Derive each candidate's independent random.Random seed from the first eight SHA-256 bytes of b'dwr-certificate-sixvar-v1\0' + root_seed unsigned-u64-big-endian + b'\0' + partition ASCII + b'\0' + candidate_index unsigned-u64-big-endian. CPython 3.11/3.12 only; seed(version=2). Select profile/cell by index modulo the fixed profile-major, A/B/C/D list BEFORE random draws; no closed-cell adaptation. Sample given positions uniformly without replacement and sort.

Draw the witness once. EQ at cells A/D uses a uniform choice among the three constant six-tuples. This explicit necessary-condition filter is prospective: a nonuniform tuple able to offer eight equality edges has a 5+1 value partition, and a five-vertex connected graph with eight edges has no bridge, so it cannot be unique with single-edge removal sensitivity. At B/C choose uniformly from the complete lexicographic tuples whose used values all occur at givens and with at least c satisfied EQ tuples. NEQ chooses uniformly from complete lexicographic tuples using all three values with at least two given values. ADD and mixed draw six independent uniform values. These are declared population filters, not outcome-selected witnesses. Empty witness sets end the attempt.

Enumerate alternatives lexicographically over unknown-value tuples, keeping givens unchanged and excluding w. Enumerate normalized tuple pools in existing grammar order. Pure source NEQ excludes pairs involving only given variables, preserving the preceding studies' explicit exception; all other pools include anchor-only tuples. All predicates for construction use only w/alternatives, never uniqueness or split membership.

Source: retain alternatives with at least one witness-true/alternative-false constraint and at least c-1 constraints true at both. Choose one feasible alternative uniformly, reserve one rejecting constraint uniformly, and sample c-1 neutral constraints uniformly without replacement. An empty feasible-alternative list ends the attempt. No extra candidate is tried. This finite pool enumeration is explicit construction work and must be counted.

Mixed: choose the first kind's alternative uniformly from the full non-w list. Enumerate distinct non-w second alternatives and retain those for which each kind has a nonempty rejecting pool and feasible positive counts summing to c. A kind's allowed pool is true at w and the OTHER alternative; its rejecting subset is false at its OWN alternative. Choose one feasible second alternative uniformly; an empty list ends the attempt without resampling the first. Reserve one rejecting constraint per kind uniformly. Enumerate lexicographic positive count vectors bounded by the allowed pools, choose uniformly, then sample each kind's remaining count from its allowed pool minus its reserved constraint. Mixed remainder may reject its own alternative; neutral-only padding is not required. Canonically sort all constraints. Every choice, including singleton choices, consumes the candidate RNG in this order. This ordered conditional proposal is not uniform over feasible alternative pairs.

Every attempt receives exactly one outcome, including empty pools, nonuniqueness, duplicates, ineligibility and envelope rejection. Persist witness, alternatives, protected constraints, finite-pool/work counters, task and independent checking metadata privately, never in model input. No uniqueness-guided internal search, refill, fallback or hidden retry. Source deletion of the protected constraint and mixed deletion of each kind must retain its corresponding alternative. Oracle-unique tasks must have scalar/oracle/reference-solver solutions exactly equal to w; disagreement is fatal, not rejection. Cross-check counts/certificates and mixed graph participation with independent predicates/audit logic. Keep givens fixed.

## Difficulty diagnostic

Implement synchronous generalized arc consistency (GAC) over the actual constraints: singleton givens, domains {0,1,2} otherwise, enumerate every local supported tuple, simultaneously intersect supported values each sweep until fixed point. Report solved/stalled, unresolved unknowns, rounds and support work. A domain-empty result on an oracle-unique task is a correctness failure. GAC is a specified weak local-inference baseline, not a learned-performance or universal-difficulty measure. Valid redundant constraints cannot manufacture a fixed-point stall. Complete equality propagation solves all unique EQ tasks; ADD is linear over F3 even when this local baseline stalls. Source GAC is descriptive and never a source-hardness gate.
