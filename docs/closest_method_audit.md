# Closest-method audit before learning pilots

2026-10-16. Targeted primary-method review for DWR's fixed-N study, extending the [LRT check](closest_lrt_check.md). Paper evidence and root inferences are separated below. This is not a systematic literature review, code reproduction or evidence of DWR's effectiveness. No paper result is imported as a DWR baseline score. No task split, architecture or run allowance changes. Independent primary-source review is READY_FOR_BOUNDED_LOCAL_PILOTS, with no Important factual/scope correction; this does not clear model/training gates.

## Frozen-decoder latent reasoning

[Latent Recurrent Thoughts,2609.01117v1](https://arxiv.org/html/2609.01117v1), sections3.2–3.5 and limitations: the existing note records its task-specific proposer, recurrent refiner, frozen decoder, soft-token injection and truncated-gradient schedule. One supervision qualification matters: StrategyQA uses a reference rationale as well as its answer. Therefore do not describe every reported task as final-answer-only. Per-task training differs from the single shared source-trained module frozen across DWR targets. Our inference: EX–IDX transfer remains a question; frozen latent refinement alone is established prior art.

[SoftCoT, ACL2025](https://aclanthology.org/2025.acl-long.1137.pdf), sections3.2–3.4 and5.1: a frozen assistant processes question plus placeholder positions; its hidden states pass through a trained projection into a frozen reasoning LLM. The objective covers rationale and answer tokens. Our inference: frozen weights and a small trainable latent interface are not new contributions. A DWR control with the same set reader would be an adaptation, not this method's reproduction. Additional assistant encoding, soft-token placement, rationale supervision and decoding costs would need separate accounting.

[Coconut,2412.06769v2](https://arxiv.org/html/2412.06769v2), section3 and4.2–4.4: continuous thoughts feed the preceding hidden state back as the next embedding. The reported curriculum gradually replaces language reasoning with continuous states; training needs repeated sequential passes, and the no-curriculum variant is separately evaluated. Our inference: DWR's answer-only, frozen-original setup cannot claim a fair reproduction by merely chaining latent vectors. Failure to learn without a curriculum would be a real limitation, not permission to add rationale supervision unnoticed.

[Scaling by Thinking in Continuous Space,2502.05171v1](https://arxiv.org/html/2502.05171v1), sections3–4: a pretrained recurrent-depth language model repeatedly conditions a random latent state on the embedded input, samples training depths and truncates recurrent backpropagation. This is the versioned page title; the initial review's different title for the same identifier is corrected here. Our inference: random initialization, repeated input conditioning and increased latent compute are prior art. This whole-model pretraining setup is external context, with substantially different training resources and trainable weights.

## Exchangeable sets and latent bottlenecks

[Slot Attention,2006.15055v2](https://arxiv.org/html/2006.15055v2), section2.1/Algorithm1,4.1–4.2 and AppendixD: independently sampled slots share update parameters; attention competes across slots and a GRU refines them. The paper proves slot equivariance and studies unseen compositions, object counts, slots and iteration counts. Our inference: exchangeable initialization, iterative slots and cardinality generalization cannot be claimed as DWR inventions. DWR uses a different residual computation/readout and studies verified language-described constraints; transferring this inductive bias remains an empirical question. Slot permutation alone cannot establish object binding or reasoning transfer.

[Set Transformer,1810.00825v3](https://arxiv.org/html/1810.00825v3), sections3.1–3.4: equivariant attention encoders and invariant attention pooling provide established set operations, including learned seed queries. Our inference: a set reader is a controlled interface choice, not standalone novelty. Keep output/readout symmetry distinct from how the initial workspace obtains identities.

[Perceiver,2103.03206v2](https://arxiv.org/html/2103.03206v2), section3.1 and AppendixC: cross-attention alternates with latent self-attention, optionally sharing weights; learned per-element initial latents provide an indexed bottleneck. Our inference: repeated attention through a latent bottleneck is established. DWR's IDX control, which adds learned identities once to otherwise matched noisy initialization, isolates its own specified identity prior; it is not an exact Perceiver implementation.

[AdaSlot,2406.09196v1](https://arxiv.org/html/2406.09196v1), sections3.1–3.3: instance-specific binary keep/drop decisions use differentiable sampling, a slot-count regularizer and a masked decoder for object reconstruction. The v1 methods are now accessible; the earlier v2 access failure remains in scratch evidence. Our inference: adaptive slot count has direct prior art and adds distinct optimization decisions. Preserve fixed-N first; externally varying N and learned allocation require different registrations.

## Compositional evaluation and resulting study obligations

[Lake and Baroni,1711.00350v3](https://arxiv.org/html/1711.00350v3), sections2–4: SCAN uses an explicit grammar/interpretation and contrasts random, length and primitive-composition splits. Our inference: new combinations, longer instances and random held-outs ask different questions. DWR must preserve its canonical/family/composition exclusions and report each transfer regime separately; no SCAN data or benchmark implementation is added.

Root decision: retain the registered shared frozen-transfer question and matched EX–IDX identity contrast. Treat K0 as interface adaptation, K1 as the one-shot computation control, and recurrence/feedforward/sequential comparisons as separate attribution requirements. A successful learning pilot supports neither cross-task transfer nor novelty; a positive confirmatory effect needs absolute ID/transfer guardrails, family-aware precision and repeated training seeds. Equal optimizer steps are not equal compute.

No faithful external reproduction is planned for the bounded local learning pilot. Before adding one, pin the authors' exact code commit and audit preprocessing/supervision, initialization, injection, trainable weights, schedules/checkpoint selection and end-to-end training/inference costs. Closest-paper reading does not substitute for that implementation audit. Before submission, refresh the search and scrutinize recent follow-ups; the review does not establish priority or a top-tier contribution.
