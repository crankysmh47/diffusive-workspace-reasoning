## Workspace contract

`FixedWorkspace(context_dim, *, num_slots=64, latent_dim=768, num_heads=12, max_steps=4, slot_identity='exchangeable')` owns one shared step norm and one shared `WorkspaceDelta` block. All dimensions/counts must be positive nonboolean integers, d divisible by heads; kind exactly exchangeable/indexed. K is a nonboolean integer0..max_steps. Initial noise is explicit caller-provided IID standard Gaussian B,N,d. A `sample_noise(batch_size, *, generator, device, dtype)` helper consumes an explicit local torch.Generator without touching global RNG; its output matches configured N/d. Parameter initializers use the caller's separate model-initialization stream, not workspace noise. Shared block parameters initialize before the added IDX embeddings so identically seeded base weights can match; decoder interface initialization uses its own matched stream in later composition.

EX has no index/position parameters or ordered masks/pooling. IDX alone adds a learned N,d embedding initialized normal(std0.02), **once** to epsilon, and reports exactly N*d additional parameters. Neither variant re-adds identities each step. K0 returns that initialization without a delta call; this does not yet implement the separately trained K0-control optimizer bookkeeping, which must omit/inactivate the unused updater and report active parameters later. K1 is exactly one application of the same residual block.

For U=LN(Z), define F concretely: a=SelfAttention(U,U,U); b=CrossAttention(U+a,X,X); c=MLP(LN_ff(U+a+b)); F=a+b+c. Both attention layers use batch_first=True,dropout0,need_weights=False; self attention is full over the set and cross attention uses actual context_dim. MLP is Linear(d,4d),GELU,Linear(4d,d). Update **Z_next=Z+F(LN(Z),X)**. Weights and norms are shared at every iteration. No graph detachment, step-specific copies or intermediate supervision.

Forward API `forward(prompt_states, *, noise, prompt_padding_mask=None, steps=4, return_states=False)`. X is B,T,context_dim, floating, finite, nonempty and requires_grad=False (frozen prompt-state contract); X's actual prompt-only provenance is the later encoder's responsibility. Noise is B,N,d,finite with exact same device/dtype as X and module parameters. Masks are B,T bool with True meaning ignored padding and at least one valid token per batch row. Unknown kinds, incompatible shapes/devices/dtypes, nonfinite input/state and all-padding fail explicitly; no truncation, promotion, fallback or answer argument. Caller inputs are never mutated. Return states optionally includes Z0..ZK without detaching, so full recurrent gradients can be checked.

## Set reader contract

`SetCrossAttentionAdapter(decoder_dim, latent_dim, *, num_heads, gate_init=0.1)` implements H'=H+g*CA(LN_H(H),LN_Z(Z),LN_Z(Z)). g is one new trainable scalar initialized0.1, identically across future methods; heads divide decoder_dim. Queries are B,L,decoder_dim; memory B,N,latent_dim, nonempty and finite, with exact matching module dtype/device. No soft tokens, fixed slot IDs or order-dependent reduction. The reader is invariant to permutation of whole final vectors for EX **and IDX**. Queries are processed independently, so changing a later query cannot change an earlier reader output with Z held fixed; native backbone causal masks and answer/prompt loss masking are still separate host tests.

Frozen decoder computations after the reader remain in the autograd graph. A CPU fixture uses a frozen linear tail with a real loss/optimizer step to prove nonzero new workspace/reader gradients and unchanged frozen weights. This is gradient mechanism evidence, not native-LM validation. The actual decoder insertion layers, prompt-only X extraction with adapters disabled, autoregressive cache, logits/loss, and tokenizer are not part of this tensor-only subsystem.
