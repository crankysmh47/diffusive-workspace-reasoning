Draw one uniformly random nonzero coefficient vector of the canonical nullspace of the ADD subset, yielding v_EQ. For each NEQ alternative build each kind's full legal witness-true pool that also accepts BOTH other-kind alternatives. Require nonempty own-rejecting EQ and ADD pools. Every linear pool row annihilates the nonzero NEQ-alternative displacement, so rank cannot exceed m-1. Skip infeasible catalog entries, without another basis path for that entry.
