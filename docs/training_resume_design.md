## Sampler

`SourceSampler(example_ids, *, seed)` owns an explicit local CPU torch.Generator. IDs are a nonempty tuple of unique lowercase SHA256 strings, in exact dataset order; seed nonboolean0..2**63-1. Keep current permutation, epoch and position; `next_ids(batch_size)` returns remaining IDs within an epoch (last batch may be smaller), and generates next epoch only on the next call after exhausting the current one. No silent drop_last/padding/replacement/reshuffle on resume. Batch size positive nonbool. Use local torch.randperm, never global RNG. `state_dict()` contains version, full ordered IDs, seed, epoch, position, current permutation and generator state; detached copies. `load_state_dict()` strictly validates exact keys/types/identity/order/full permutation and cursor before any mutation. State after epoch exhaustion is valid; tests cover both boundary and partial epoch. Sampler is a source driver primitive, not a membership proof; training loader later restricts all IDs to approved source_train.

## Checkpoint APIs

`save_training_checkpoint(path, *, host, optimizer, scheduler, scaler, sampler, noise_generator, identities, progress)` and `load_training_checkpoint(path, *, expected_sha256, host, optimizer, scheduler, scaler, sampler, noise_generator, identities) -> progress`.

Host must be actual `Qwen2WorkspaceLM`, all original backbone weights frozen, no outstanding hooks/active host call, no nonfinite new tensor. Caller invokes only at an optimizer boundary **after zero_grad(set_to_none=True)**: reject any parameter.grad is notNone. No gradient accumulation resume is promised. Save `workspace.state_dict()` and `readers.state_dict()`, including frozen K0 workspace/IDX identities, rather than copying pretrained weights into every checkpoint. Include exact host configuration (N,d,workspace.num_heads,Kmax,slot_identity,prompt layer, reader indices/heads), named parameter/buffer shapes/dtypes and requires_grad flags, and ordered named active parameter groups. Optimizer parameter set must equal exactly current requires_grad new parameters, with no duplicate/missing/frozen/original entries. Optimizer group order/name mapping is bound on load so same-shape reordered groups cannot silently swap moments. Optimizer/scheduler concrete type names must match; scheduler is required and state saved. Require scheduler.optimizer is exactly the supplied optimizer on save and load; bind workspace.num_heads even when parameter shapes coincide. Scaler is explicit None for disabled scaling, otherwise actual GradScaler with matching enabled policy/state. No generic arbitrary stateful object support. Initial supported optimizer is torch.optim.AdamW and scheduler torch.optim.lr_scheduler.LambdaLR with caller-supplied prospective schedule identity; future optimizers require separate explicit support. A lambda function is not serialized; its identity and config are bound by identities, plus current scheduler state. Tests must actually exercise nonconstant schedule and nonempty Adam moments.

`identities` exact keys: source, config, data, model, tokenizer, schedule; each lowercase SHA256 string. These bind the resolved consumer identities, not the checkpoint's own hash; reject null/extra keys or changed identities. Source is exact source inventory digest, data is exact consumed manifest digest, model/tokenizer refer to pinned files/revision manifests. Caller separately verifies frozen base files when constructing host; checkpoint does not rehash multi-GB base tensors at every save. Correctness tests independently compare all tiny base tensors bytewise. This helper cannot certify that an arbitrary caller-supplied model hash represents its live base; later launcher owns that binding.

`progress` exact keys optimizer_step, examples_seen, supervised_tokens_seen; nonnegative nonbool integers. Capture full sampler state, explicit training noise generator device/state, Python random.getstate, NumPy legacy random state, Torch global CPU state and **all already-initialized CUDA RNG states/device identities**. Do not initialize CUDA solely for a CPU save. Bind CPU-vs-CUDA initialization/device layout on resume; fail rather than silently omitting/changing it. Encode NumPy state using primitive values and a tensor for the uint32 array, not arbitrary NumPy pickle objects. Torch checkpoint loads with weights_only=True, CPU map_location, after byte-hash validation. No file downloaded or untrusted pickle load. Restore generator/global RNG only after all identity/shape/state validations and model/optimizer/scheduler/scaler loads succeed. Explicit noise device must match; scheduler state and optimizer groups/moments must be finite and consistent. Validate saved model keys/shapes/dtypes/flags and all nested known checkpoint keys before load; reject unknown/incompatible/corrupt data. An apply-time library failure is fatal: caller discards the partially restored host/optimizer and does not continue training. No expensive full-base rollback copy.

Save only a new file, Windows-safe exclusive path, no symlink/reparse chain, stable checkpoint schema version. Write to an exclusive sibling temp, flush/fsync, then atomic destination creation that cannot replace an existing checkpoint; preserve failed temporaries. Return SHA256 and byte size. Do not claim byte-identical torch.save output across versions. Hash before load and after reading to detect changed input; no fallback or silently missing component. Load is from trusted local artifact bytes already bound in run manifest.
