## Scope and routing

Export exactly all accepted `source_train` and `source_validation` records from the complete five-stratum run:2436 and265 respectively. No source ID-test, development or final task/answer may be consumed or exported. These permission checks precede interpretation of private task/witness/value fields. Whole-file SHA checks read opaque bytes of all six retained artifacts; JSON parsing of the full raw ledger necessarily materializes private fields before routing. Log this precisely: protected payloads are not semantically consumed, but do not claim protected file bytes were never read. No source validation row enters an optimizer in the later driver.

Inputs are the six exact full-run artifacts listed in `configs/splits/certificate-five-stratum-study-result.json`, with full configSHA `3aff6fcaba6143a26ad6d8a86cc83f9782ff63d689912f5fb04ffc4e9cc81afa`, clean producer `6ad827784e3887295db05c4e1e651f6e5a6648f3` and terminal `PASS_G2_FIVE_STRATUM_V1`. Output is ignored, not Git data. Never regenerate, draw new examples, refill a cell, recalculate split assignments or alter thresholds.

## Module and API

New standard-library `dwr/experiments/source_corpus.py`, no eager training/Torch import. One pure conversion core `export_source_records(input_dir, output_path, *, expected_artifacts, generation_config_path, expected_config_sha256, expected_source_commit, expected_counts, check)` and separate later CLI/run wrapper. `expected_artifacts` must contain exactly the six known basenames with lowercase SHA256 strings. `expected_counts` exactly source_train/source_validation positive integers. Production wrapper will supply committed exact hashes; fixture tests supply tiny retained ledgers with their own bindings. This conversion function is not itself a production authorization entry point. `check` is required callable resource guard, invoked before/after hashing and each line/solver/oracle loop boundary. Output path must not exist, and must not overlap any input artifact; reject symlink/reparse chains and unsafe paths. No fallback/skip/truncation.

Hash and compare all six files before semantic access. Strictly parse terminal/initial/report/replay JSON using duplicate-key/nonfinite-rejecting loader. Require exact config identity across manifests/report, matching clean producer commit in both manifests, matching initial resolved config by exact typed comparison with the object parsed from generation_config_path after verifying that original file bytes match expected_config_sha256 (never compare the SHA of reserialized JSON to the original pretty-file hash), terminal/report statuses and g2 `pass`, report.fixture_only exactlyFalse, replay `PASS_REPLAY` and exact indices true. Verify terminal artifact map's recorded hashes against supplied hashes wherever declared, without assuming the terminal manifest hashes itself. Reuse producer schema knowledge from existing code rather than guessing metadata shapes. No forced full regeneration/replay: those checks already passed in the immutable hashed G2.

Read `records.jsonl` streaming. It is an accepted-A projection with outcome-line SHA, routing, task input SHA and annotations. Validate routing key types; candidate_index nonnegative nonbool; partition/split compatible. Reject duplicate `(partition,candidate_index)` and duplicate content IDs across this accepted ledger. Allow only known split names from existing task code. For source_train/validation require source partition, exactly one allowed primitive profile, `oracle_unique`, `eligible`, `sensitive` and `envelope` exactlyTrue, valid content/lineage/model_input/outcome hashes and fine_stratum among A2/A3/B2/C2/D2. Preserve metadata without claiming counts are independent families. Do not inspect the projection's `values` for forbidden splits. Keep only the allowed projection index in memory. Require exact expected counts before raw payload interpretation.

Stream `outcomes.jsonl`, strict JSON. Route on partition/index and split first. Unknown/malformed routing and duplicate raw keys fail. A raw row with split=null is permitted only for state=construction_failed with valid partition/index; count it and skip its private fields. Add a poisoned-private-payload regression for this valid rejected-row state. For keys absent from allowed projection, skip all private task/witness/values interpretation; count skipped rows by routing only. For an allowed key, require source allowed split and exact raw line bytes SHA equal projection.outcome_sha256, then exact `_a_projection(row)` plus outcome SHA equals public record (reuse existing producer projection, with independent mutation fixtures). Require first_seen_content exactlyTrue. Interpret only now the top-level `task` serialized JSON string using strict task parser. Match exact SHA256 of `serialize_model_input(task)` (without the prospective newline) to model_input_sha256; require primitive kinds equal profile. Recompute existing content/lineage/structure identities and compare public IDs. Do not use witness or values to derive gold.

Use deterministic reference solver AND independent exhaustive tiny oracle. Require solver solution_count1, oracle exactly one solution, identical canonical assignments and strict verifier acceptance. This independently derives permitted source gold; generator witness cannot certify itself. No task canonicalization relabeling or split reassignment. Call guard around these bounded n<=6 operations; reject nonfinite/unknown invalid data. Preserve all accepted examples in original records order (not raw incidental order). Every allowed key must match exactly one raw row; no missing/phantom duplicates. Hash inputs again after processing before success and fail if bytes changed. Caller writes failed record on any exception; partial output remains ignored evidence.

Output JSONL, exclusive UTF-8/LF: exact fields `schema_version` (`dwr-source-example-v1`), `example_id`=content_id, `split`, `lineage_id`, `structure_signature`, `fine_stratum`, `profile`, `model_input_sha256`, `task`=canonical serialized strict task string, `solution`={assignment:{v0:..., ...}}, `origin`={partition,candidate_index,outcome_sha256}. Gold stays separate from prompt; later training loader constructs SourceExample and collator validates again. Do not put solver annotations/private raw witness into model input. Return a small JSON-safe summary of exported counts/fine counts, permitted payload accesses, skipped raw rows, input/output hashes and total records. Null denotes unavailable separate costs; wall/CPU/RSS measured by wrapper.
