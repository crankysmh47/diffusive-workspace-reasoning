# Native greedy evaluation component

2026-10-15 prospective root design, under the [native contract](native_backbone_design.md) and [protocol](research_protocol.md). No actual corpus, pretrained inference, GPU operation or scientific evaluation in implementation. Luna implements; separate review follows. This is a bounded algorithm/component, not a target-evaluation launcher.

## API and semantics

New `dwr/evaluation/generation.py`, empty initializer and focused tests. `greedy_workspace(host, prompt_ids, prompt_mask, *, noise, steps, eos_token_id, max_new_tokens, max_total_tokens)` and `greedy_frozen(backbone, prompt_ids, prompt_mask, *, eos_token_id, max_new_tokens, max_total_tokens)` return immutable `GenerationResult(token_ids, eos_token_id, ended_with_eos, truncated, prompt_tokens, decoder_calls, prompt_encoder_calls, workspace_updates, elapsed_wall_seconds)`. Token IDs include terminal EOS if generated; all Python count/bool types strict and finite. Validate result invariants: nonempty tuple of nonnegative nonbool IDs, nonnegative eos_token_id (generation separately checks vocabulary bounds), EOS appears only at the end and exactly when ended_with_eos=True, truncated is its logical inverse, decoder_calls=len(token_ids), nonnegative integral counts and finite nonnegative wall time. Score rejects malformed result metadata. CPU execution only initially; require model and all input/noise tensors on CPU, fail on CUDA rather than silently moving tensors. Later registered GPU timing extends this explicitly with synchronization/memory measurements. CPU elapsed includes the entire prompt encoding/workspace/generation section, not token-only time; FLOPs and GPU memory remain unavailable, not zero.

Single-example, no padding: prompt_ids shape1,L nonempty long, prompt_mask exactly allTrue Boolean, valid vocab IDs. Eos is in model embedding vocabulary, positive nonbool caps and L+max_new_tokens<=max_total_tokens, strict finite logits/noise/shape and K bounds. Prompt contains no EOS/pad (framing collator later owns it); EOS token bounds checked here. Unknown args fail. Native backbone is frozen/eval, cache/hidden-state/attention recording off, no foreign hooks or gradient checkpointing. Frozen baseline requires actual Qwen2ForCausalLM, config.return_dict True (reject False explicitly rather than mutating caller config), no trainable original parameter. Workspace path requires actual verified Qwen2WorkspaceLM in eval mode; learned flags may stay requires_grad for source validation between optimizer steps, but no operation is differentiable or updates a parameter during evaluation. Target freezing is enforced by future registered driver. Preserve all mode/flag/RNG states and clean host hooks after success/failure; do not force train/eval modes silently.

Workspace path encodes X once with host.encode_prompt, computes Z once using explicit noise and detached X with the existing precision casts/autocast-off policy, then retains **the same complete final Z for every answer step**. No noise resampling, workspace evolution or extra prompt re-encoding per generated token. Decode full current prompt+generated prefix with host.decode_with_workspace, cache disabled, choose argmax at final valid position, append exactly one ID, stop on EOS or cap. Use torch.no_grad for inference; this does not change training host behavior. Count actual prompt_encoder_calls1, workspace_updates=steps, decoder_calls=generated tokens. Frozen path has prompt_encoder_calls0 and workspace_updates0; each decode includes original full prefix. Report actual different cost, no simultaneous matching claim. Decoder logits are finite1,current_length,V and vocabulary width must match model embedding width; tie break argmax's first index.

Keep a small private greedy loop if useful for unit tests; no generic model abstraction or generate()/KV cache fallback. Tests may script callback logits for algorithm correctness, explicitly labeled unit tests; **actual native-model fixtures are separately mandatory** and cannot be replaced by scripted evidence.

`score_generation(task, result, tokenizer)` returns JSON-safe fields answer_text, valid, verifier_reason, termination, generated_tokens. Validate actual ConstraintTask/result and tokenizer.decode callable. Remove only the final EOS when ended_with_eos; decode all remaining IDs with skip_special_tokens=False, clean_up_tokenization_spaces=False. Decode must return str. If result.truncated, count failure regardless of whether the text happens to parse as a valid assignment; still preserve strict verifier reason as a separate diagnostic. Termination is eos or token_cap; strict verifier is existing verify_answer, no regex repair, code-fence removal, search, retries or best-of-noise. No requested example disappears from denominator.

`evaluation_noise_seed(training_seed, example_id, *, draw_id=0)` derives a nonnegative63-bit integer from SHA256 of a versioned stable JSON tuple/object, with exact string/domain documented in code. training_seed/draw_id nonnegative nonbool integers, example_id lowercase64SHA. Seed must not depend on batch order, method/EX-IDX, K or answer. Caller creates explicit noise generator and records draw identity; helper never changes global RNG. Same noise shape/dtype/device must be shared across matched methods. Single predetermined draw is default; more requires registration, not verifier selection.

## Meaningful checks

Scoped TDD CPU tests: scripted unique nonuniform logit maxima establish exact emitted IDs, EOS inclusion, first-index tie break, cap termination and strict decoding kwargs; a syntactically valid answer lacking EOS still fails at cap. Invalid/malformed/nonfinite inputs/logits/caps and unknown args fail, not skip. Noise seeds stable under reversed example order and differ by example/draw/training seed; no global RNG mutation. Strict verifier catches malformed/incorrect answer text.

Actual tiny random Qwen2 fixtures with isolated backbone/workspace/readers seeds, caller local noise, threads restored: compare loop output to independently repeated manual native forwards, confirm single X/Z computation and same Z across calls, original/new parameters and RNG unchanged, host hooks clean after a forced actual native layer failure. EX and IDX whole-final-slot permutation behavior stays covered by native host tests; no fresh scientific symmetry claim from this loop. Native fixture also exercises greedy_frozen on the original decoder with no inserted interface. CUDA/scaler/performance evidence deferred.

No weights/tokenizer download, actualdata/model-quality scoring, protected access, full suite, dependencies or commit in this component. Later exact source loader and registered per-example run wrapper must bind IDs/families/prompt/checkpoint hashes, decoding/noise policy and complete counts, enforce resource/test-access gates and report costs. Completing the component does not check off repeatable pretrained frozen evaluation or G3.
